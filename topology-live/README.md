# SolidCraft 实时拓扑命名查看器

先在自己的 Windows 登录会话中启动 SolidCraft，再双击 `start-live-viewer.cmd`。
启动窗口会列出当前账号可连接的实例（文档名、进程 PID、控制端口），输入序号选择。
查看器会自动申请一个空闲网页端口，并打开对应浏览器地址；保持启动窗口运行，按 Ctrl+C 停止。
启动脚本会依次寻找 `py -3`、`python` 和系统安装的 Python 3.12，需要 Python 3.10 或更新版本。

也可在本目录执行：

```powershell
py -3 .\server.py --open
```

网页地址类似 `http://127.0.0.1:52341/`，以本次启动窗口输出为准，不再默认占用固定的 8767。
无需安装 Python 包，也无需修改 SolidCraft 安装文件或 Codex 配置。

## 多用户与实例选择

- 每个用户都应在自己的 Windows 账号下启动一份查看器；同机多个查看器的网页端口由系统分别分配。
- 默认只从启动账号的 `%LOCALAPPDATA%\SolidCraft\control` 目录发现实例；
  设置了 `SOLIDCRAFT_CONTROL_DIR` 时使用该目录。不会搜索其他用户的配置目录。
- 启动后固定所选实例的原生控制端口及本次启动凭据，不再跟随 `current.port`。
  暂时断线时只尝试重连原实例；原实例退出或同端口换成另一次启动的实例时，保留上次快照并提示。
  此时重新启动查看器，明确选择要连接的实例。
- 同一份查看器地址下的浏览器共享模型快照和“立即刷新”请求。
  不同查看器进程有各自的采集线程、缓存和临时导出文件。
- 各用户可共用只读的程序文件；临时网格放在启动账号自己的 `%TEMP%\SolidCraftTopologyViewer\session-*`。
  不需要其他用户写入程序目录。使用同一份程序文件时，更新这些文件会影响各用户后续启动的版本。

命令行可先查看实例，再按原生控制端口直接指定连接来源：

```powershell
py -3 .\server.py --list-instances
py -3 .\server.py --control-port 27879 --open
```

也可给启动脚本传同样的参数：

```powershell
.\start-live-viewer.cmd --control-port 27879
```

`--control-port` 是 SolidCraft 原生控制端口；`--port` 是查看器网页端口，两者用途不同。
网页端口默认 `0`（由系统分配空闲端口）；需要固定地址时可使用 `--port 8768`，端口被占用则启动失败。
使用自定义控制目录的 SolidCraft，可加 `--control-dir 'D:\MySolidCraftControl'` 指定对应目录。
实例选择仅在每次启动时进行，不保存或打印 SolidCraft 的控制凭据。

查看器通过 SolidCraft 自带的本机控制通道读取当前设计。它查询文档版本、面名、边名，
在版本变化后导出一份带面标签的临时显示网格。它不提供 CAD 写命令接口，不会创建、
删除或修改原模型特征。默认同时显示全部可见实体，也可选择单个实体隔离查看；新建
或切换文档后自动更新。新增实体后整体视图重新适配范围，避免新增形体落在画面外。

## 实时的范围

- 默认每 0.7 秒检查轻量文档版本；停止连续修改后采集，单次采集期间不会再启动第二次。
- 操作提交、重算完成后刷新；鼠标移动中的临时预览不属于已提交的持久拓扑。
- 复杂模型的导出、测量与处理耗时会延长刷新间隔。网页显示采集状态和更新时间。
- 所选 SolidCraft 实例暂时断连时保留上次结果并明确显示等待状态，只重连同一次启动的原实例。
  原实例退出后重新启动 SolidCraft，需要重新启动查看器选择，避免自动连接其他实例。
- “立即刷新”向唯一采集 worker 请求重新读取 CAD，即使文档版本号没有变化也会采集。
  连续点击会合并请求，不会并发导出；操作中模型再次变化时，等待一致快照再显示。
- 暂停页面刷新后，后端在 15 秒无客户端轮询后停止 CAD 查询；服务器仍可被重新打开。

## 名称与编号

- 面、边的完整名称直接来自当前 SolidCraft。
- f/e 是当前快照的显示索引。当前快照的原生名称、原索引、`exact` 的存在性和值在发布前逐项核对。
- P 是端点坐标去重后的展示编号，不是独立的持久顶点名称。构造几何引用顶点时可保存
  相邻边名集合，并在更新后寻找共同端点。点详情中展示这种等价引用对象，仅供理解，
  不会写入 SolidCraft。
- 面按带原生 B-rep 面索引的网格三角形显示；边没有原生导出索引标签，使用邻面、端点与原生采样证据重建。无法唯一匹配、出现路径冲突或超过预算时，不绘制该边的具名曲线、标签和画布拾取，目录保留原始记录并显示警告。
- `exact:true/false` 是 SolidCraft 原生历史来源状态，不是名称提取是否成功。`false` 可来自几何回退命名或未确认的分片顺序；缺失字段显示“未返回”，不会默认为 true。它们均不构成任意编辑后永久不变的承诺。
- 元素详情可展开 SolidCraft 原始查询记录。名称、索引、历史字段或面标签校验失败会拒绝新快照并保留旧图。
- 同一版本刷新可保留选择；跨重算仅尝试保留同名且新旧均 `exact:true` 的面。其他选择会清除，要求重新选择。

## 本机范围与资源上限

HTTP 只监听 `127.0.0.1`，API 使用同源会话，不将 SolidCraft 控制 token 发给浏览器。
本机访问限制和不同端口不提供 Windows 用户身份鉴权；知道网页地址的其他本机用户仍可访问。
如果不同用户的模型需要保密，还需要额外的访问凭证或系统访问控制。
文件仅导出到启动账号 `%TEMP%\SolidCraftTopologyViewer\session-*`，正常退出只清理本次已知的临时网格和会话目录。
上限为 32 个实体，单次 API 数据 16 MiB；网格解析另有顶点、三角形和解压大小限制，
并按三角形与边采样点的乘积限制软件渲染工作量。
达到上限时保留上次结果并显示错误，不承诺任意规模模型的刷新性能。
同一超限版本不会反复导出；修改模型产生新版本后再尝试采集。

## 原窗口叠加的区别

SolidCraft 0.30.1 的插件页只管理清单，尚不执行插件代码。这个程序使用独立浏览器窗口。
若要将名称文字直接画在 SolidCraft 原生视口内，需要扩展 ui-egui 源码并重编译。
