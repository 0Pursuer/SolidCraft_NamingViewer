# Lifecycle 提交前复核（2026-11-10）

本次为主审自审，依据 requesting-code-review、system-software-audit 和 verification-before-completion 执行。基线为 `9b7ad46`，范围为 lifecycle 展示模型、GET 接口、前端及其与原重算页面的集成，没有独立子代理审查。

## 已复现并修复

1. **干净检出的测试导入失败。** 原 `test_lifecycle_real.py` 在模块加载时对默认空值 `REAL_ARCHIVE` 调用 `resolve()`，且依赖个人绝对路径和固定实验编号。默认环境已复现 `AttributeError`。现由测试自动创建原生样例和独立 CLI 实验，测试档案、任务和服务均归测试所有，退出时清理。
2. **集成回退了已有取消/轮询保护。** 旧实验取消的迟到响应可以覆盖新选择；A → B → A 后，第一轮 A 的迟到轮询也可覆盖重新选择的 A。前者由已有浏览器回归、后者由新增回归在独立副本中分别复现。保留 lifecycle 事件通知，同时恢复已提交的选择代次检查；旧响应和错误不得写入新选择。
3. **计数与修改证据校验不一致。** 中间回复帧校验了编辑参数，完成阶段却只看命令名称便显示计数。四种不匹配（目标特征、距离、回复特征、缺失参数）均已在回归中复现。现在两处共用证据校验；无法匹配时计数为未提供，导出几何和定义可独立作为阶段事实显示。
4. **切换观察时的连接中止被误报。** 浏览器主动取消 GET 后可产生 Windows `ConnectionAbortedError`，服务原先试图向已断开的连接再发错误回复。GET 与已有 broken-pipe/reset 路径一样直接结束，避免重复异常输出。
